# VoiceMagic 微信音量

Windows 桌面工具，将整个微信的播放声音独立调节到 0–1000%。包含聊天语音、视频、提示音和通话声音；其他软件继续使用原有输出。

## 启动

日常使用双击 `release/VoiceMagic.exe`。这是单文件分发版，包含运行依赖、音频路由工具和官方虚拟声卡安装文件，无需同时携带 DLL 或文件夹。

首次运行会将启动器保存到 `%LOCALAPPDATA%/VoiceMagic/VoiceMagic.exe`，并将运行组件释放到该目录下按程序包哈希区分的 `runtime` 子目录。以后移动或删除最初下载的 EXE，不影响已启用的开机启动。该步骤无需管理员权限；安装虚拟声卡仍需一次管理员授权。

开发时也可使用项目根目录的 `启动微信音量.cmd` 或 `dist/VoiceMagic.exe`。

首次使用：

1. 在「设置」点击「安装音频组件」，允许管理员权限，在官方安装窗口点击 **Install Driver**，按提示重启电脑。
2. 重新打开工具，在「设置」点击「刷新设备」，选择「跟随系统默认播放设备」或指定耳机。
3. 单击托盘图标打开音量面板，打开「放大」开关，播放一条微信语音，从 200% 开始调节。

安装程序是 VB-Audio 官方 VB-CABLE Pack45，构建时验证 SHA-256 和安装器签名。需要管理员授权的步骤仅为驱动安装。工具日常运行无需管理员权限。

## 工作方式

微信 → CABLE Input → CABLE Output → 实时增益与峰值限幅 → 所选耳机/扬声器。

使用 NAudio/WASAPI 处理 32 位浮点音频，15ms 增益平滑、联动立体声限幅、120ms 释放。1000% 表示振幅增益上限 10 倍，实际响度取决于原音频和峰值保护。音频仅在内存中处理，无录音文件、网络上传或微信账号访问。

工具通过 SoundVolumeView 修改微信及其插件的应用输出分配，每两秒根据当前音频会话复查路由。即使同一个微信进程保留了旧的 CABLE 会话，只要新声音转到其他设备，也会重新接入；QQMusic 的同名插件进程会被排除。不会改动系统总音量、系统默认设备或其他应用输出。

选择「跟随系统默认播放设备」时，工具会跟随 Windows 默认播放设备变化。面板顶部显示等待播放、正在放大或微信未接入；底部的重新连接图标可重新建立音频通道。

关闭「放大」开关或在托盘菜单选择「恢复并退出」时，将微信输出设为**跟随系统默认设备**。如果微信之前指定了独立设备，需要自行在 Windows 音量设置重新选择。崩溃时独立守护进程尝试恢复；下次启动也会检查恢复标记。可双击 `恢复微信默认输出.cmd` 执行恢复，程序运行时该命令也可直接通知现有实例恢复。

## 托盘面板

单击托盘图标打开或收起面板；点击外部、按 Esc 或关闭面板会收起，音频继续在后台处理。面板不会占用任务栏窗口按钮，再次运行启动脚本会唤起现有面板。

面板提供 0–1000% 滑块、静音、声音电平、放大开关、重新连接和设置入口。滑块支持拖动、方向键和滚轮微调，Home/End 跳转至 0%/1000%。

设置入口为右下角齿轮，也可从托盘右键菜单打开。设置窗口独立于面板，关闭设置不会停止音频。设备选择会在放大运行时重新建立通道，并保留音量与静音状态。

退出程序请使用托盘右键菜单「恢复并退出」。手动启动后先显示面板一次，仍需打开「放大」开关。设置与故障日志位于 `%LOCALAPPDATA%/VoiceMagic`。

## 开机启动

在设置中勾选「开机启动」，即可在当前用户登录 Windows 后静默驻留托盘，并按保存的音量、播放设备自动开启放大。取消勾选立即移除该启动项，默认关闭。

开机启动使用当前用户的 Windows Run 项，不需要管理员权限。音频设备暂未就绪时在后台每 10 秒重试；不会自动弹出面板或安装窗口。重复的开机启动请求不会唤出已有面板。主动关闭放大后不会自动重新开启。

## 注意事项与排查

- 安装驱动后，确认 Windows 的默认播放和录音设备仍是原来的耳机、扬声器和麦克风。不要把 CABLE 设为系统默认设备，也不要把 CABLE Output 打开「侦听此设备」。程序在默认播放设备为 CABLE 时会拒绝开启。
- CABLE 应仅供本工具处理微信使用，其他软件若也输出到同一 CABLE，会一起被放大。
- 开启后电平无变化：重新播放语音；必要时手动退出再启动微信。部分微信版本或通话内手动指定设备会覆盖 Windows 的应用路由，应在微信中选择系统默认播放设备。
- 使用「跟随系统默认播放设备」可自动跟随默认输出切换。明确指定的设备断连后，请刷新并重新选择，或点击重新连接图标。蓝牙通话模式可能增加延迟或降低音质。
- 普通共享模式音频会增加少量处理延迟，通话时建议使用耳机。峰值保护无法修复源音频原有的失真。
- 若先退出微信再停止工具，Windows 可能保留已关闭进程的输出分配。建议先停止工具再退出微信；重新打开微信后点击「恢复默认输出」也可恢复。
- 工具停止期间声音仍异常：打开 Windows 音量设置，把微信输出设回默认；重播语音或重新打开微信。
- 微信在管理员权限运行时，应用路由可能需要相同权限。

## 构建和验证

无需 Python、Node.js 或安装 .NET SDK。使用 Windows 自带 .NET Framework 4.x C# 编译器，运行需要 .NET Framework 4.7.2 或以上，x64 Windows 10/11。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

生成单文件分发 EXE：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/package.ps1
```

产物为 `release/VoiceMagic.exe`，附带 `release/SHA256.txt`。程序包启动时会验证内嵌载荷 SHA-256，释放时限制所有路径留在专用运行目录内。打包不包含测试程序或界面验证图片。日常使用仍依赖 Windows 自带的 .NET Framework 4.7.2+。

构建脚本通过本地 `http://127.0.0.1:10808` 代理下载官方依赖。直连可加 `-Proxy ''`。下载缓存、外部组件和生成目录不进入 Git。SoundVolumeView 上游 ZIP 更新后哈希会改变，须核实来源和新版本后手动更新校验值。

构建自动验证实际增益、立体声比例、突发峰值保护、静音、0% 和异常采样，以及本机 Windows 音频设备枚举。首次安装驱动后还需播放微信语音，检查电平、独立放大和停止恢复；未完成该步骤时，不视为端到端声音验证通过。

`dist/VoiceMagic.Tests.exe --integration` 使用极低音量测试信号，实际经过 VB-CABLE、音频引擎和默认播放设备，验证两轮开启/停止及三倍增益。需要已安装 VB-CABLE。`--diagnose` 仅读取微信音频会话状态，不修改路由。

`dist/VoiceMagic.UiTests.exe` 检查 100%、150%、200% 控件布局、1000% 文本显示和四种任务栏方向的定位，并在 `dist/qa` 生成真实 WinForms 控件的离屏渲染。`--lifecycle` 使用实际音频引擎检查面板收起/关闭、设置关闭时的后台存活，以及重新连接、停止恢复。生命周期检查不显示窗口或创建托盘图标。

界面测试还在临时注册表键中验证开机启动的路径引用、启用和取消，不改动用户真实的 Run 项。`--startup-lifecycle` 检查静默启动、自动放大、后台驻留及主动停止。

新界面使用 ApplicationContext 管理后台生命周期，浅灰面板、细滑块和线性图标参考 `docs/ui-reference.png`。Fluent 图标作为 PNG/ICO 嵌入程序，日常运行无需 Node.js；`scripts/prepare-icons.cjs` 仅用于开发时从原始官方 SVG 重建资源，需要 sharp。

第三方许可见 `THIRD_PARTY_NOTICES.md` 及分发目录中的官方说明。VB-CABLE 与 SoundVolumeView 为独立第三方产品。
