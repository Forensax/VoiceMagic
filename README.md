# VoiceMagic 微信音量

Windows 桌面工具，将整个微信的播放声音独立调节到 0–600%。包含聊天语音、视频、提示音和通话声音；其他软件继续使用原有输出。

## 启动

双击项目根目录的 `启动微信音量.cmd`，或打开 `dist/VoiceMagic.exe`。

首次使用：

1. 在「设置」点击「安装音频组件」，允许管理员权限，在官方安装窗口点击 **Install Driver**，按提示重启电脑。
2. 重新打开工具，在「设置」点击「刷新设备」，选择耳机或扬声器。
3. 回到「音量」，点击「开启放大」，播放一条微信语音，从 200% 开始调节。

安装程序是 VB-Audio 官方 VB-CABLE Pack45，构建时验证 SHA-256 和安装器签名。需要管理员授权的步骤仅为驱动安装。工具日常运行无需管理员权限。

## 工作方式

微信 → CABLE Input → CABLE Output → 实时增益与峰值限幅 → 所选耳机/扬声器。

使用 NAudio/WASAPI 处理 32 位浮点音频，15ms 增益平滑、联动立体声限幅、120ms 释放。600% 表示振幅增益上限 6 倍，实际响度取决于原音频和峰值保护。音频仅在内存中处理，无录音文件、网络上传或微信账号访问。

工具通过 SoundVolumeView 仅修改 Weixin、WeChat、WeChatAppEx 的应用输出分配，每两秒发现微信的新音频会话并继续应用。检测到会话实际出现在 CABLE 后才将其标记为已路由。不会改动系统总音量、系统默认设备或其他应用输出。

停止、关闭窗口或托盘退出时，将微信输出设为**跟随系统默认设备**。如果微信之前指定了独立设备，需要自行在 Windows 音量设置重新选择。崩溃时独立守护进程尝试恢复；下次启动也会检查恢复标记。可双击 `恢复微信默认输出.cmd` 执行恢复。

最小化会进入托盘，双击托盘图标恢复窗口。直接关闭窗口会停止并退出。设置与故障日志位于 `%LOCALAPPDATA%/VoiceMagic`。

## 注意事项与排查

- 安装驱动后，确认 Windows 的默认播放和录音设备仍是原来的耳机、扬声器和麦克风。不要把 CABLE 设为系统默认设备，也不要把 CABLE Output 打开「侦听此设备」。程序在默认播放设备为 CABLE 时会拒绝开启。
- CABLE 应仅供本工具处理微信使用，其他软件若也输出到同一 CABLE，会一起被放大。
- 开启后电平无变化：重新播放语音；必要时手动退出再启动微信。部分微信版本或通话内手动指定设备会覆盖 Windows 的应用路由，应在微信中选择系统默认播放设备。
- 耳机切换、设备断连后，请停止、刷新设备、重新选择并开启。蓝牙通话模式可能增加延迟或降低音质。
- 普通共享模式音频会增加少量处理延迟，通话时建议使用耳机。峰值保护无法修复源音频原有的失真。
- 若先退出微信再停止工具，Windows 可能保留已关闭进程的输出分配。建议先停止工具再退出微信；重新打开微信后点击「恢复默认输出」也可恢复。
- 工具停止期间声音仍异常：打开 Windows 音量设置，把微信输出设回默认；重播语音或重新打开微信。
- 微信在管理员权限运行时，应用路由可能需要相同权限。

## 构建和验证

无需 Python、Node.js 或安装 .NET SDK。使用 Windows 自带 .NET Framework 4.x C# 编译器，运行需要 .NET Framework 4.7.2 或以上，x64 Windows 10/11。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

构建脚本通过本地 `http://127.0.0.1:10808` 代理下载官方依赖。直连可加 `-Proxy ''`。下载缓存、外部组件和生成目录不进入 Git。SoundVolumeView 上游 ZIP 更新后哈希会改变，须核实来源和新版本后手动更新校验值。

构建自动验证实际增益、立体声比例、突发峰值保护、静音、0% 和异常采样，以及本机 Windows 音频设备枚举。首次安装驱动后还需播放微信语音，检查电平、独立放大和停止恢复；未完成该步骤时，不视为端到端声音验证通过。
